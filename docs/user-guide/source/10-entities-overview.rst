Entities: overview
==================

Archival entities are the persons, families, corporate bodies, places and
concepts that the description of a fonds refers to - as creators, as
archivists and as access points (:doc:`06-creators-and-access-points`).
They are described once, in a **scope of entities**, with the rule set
*ISAAR(CPF) entity description* (the rules package ``ISAAR_CPF``), which
brings the *International Standard Archival Authority Record for
Corporate Bodies, Persons and Families* into ELZA, with places and
concepts beside the three kinds of agents.
