===============
ELZA User Guide
===============

ELZA is a web application for processing archival materials and preparing
finding aids. This guide is for archivists who describe fonds with the
international rule set **ISAD(G)** and archival entities - persons,
families, corporate bodies, places and concepts - with **ISAAR(CPF)**.
Both come with ELZA as rules packages; an installation enables them in its
configuration (see the administration guide, "Loading the packages").

The Czech rules (ZP2015 for the description of fonds, CAM for entities)
and the Czech user documentation are published separately in Czech.

Part I describes the description of fonds, part II the entities the
description refers to.
