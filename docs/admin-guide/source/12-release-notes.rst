=============
Release Notes
=============

The list of changes of every build, for users and administrators alike.
It is the English version of the Czech list *Změny v jednotlivých
sestaveních*, without the changes of the Czech description rules (ZP2015)
and code lists (CZ_BASE), which are listed only in the Czech
documentation.

Entries start with a category - **New**, **Change**, **Fix** or
**Removed** - followed by the issue number, where there is one. Entries
that require an action of the administrator name the configuration key
and link to the relevant chapter of this guide.
