=========================
ELZA Administration Guide
=========================

ELZA is a web application for processing archival materials and preparing
finding aids. This guide is for administrators who install, configure,
upgrade and operate an ELZA instance, and for integrators who connect it
to other systems.

Archival description rules (ZP2015), methodics and the user guide are
published separately in Czech.
