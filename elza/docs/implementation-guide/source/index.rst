==========================
ELZA Implementation Guide
==========================

This guide is for implementers who prepare rules packages and customize the
archival description rules of an ELZA installation. Installing, configuring
and operating ELZA is described in the administration guide.

The Czech archival description rules (ZP2015) and their methodics are
published separately in Czech.
