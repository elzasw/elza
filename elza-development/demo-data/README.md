# Demo data

Sample funds for trying out Elza and for demonstrations. Each file is an EDX import
(`elza-core/src/main/resources/schema/elza-schema-v2.xsd`) and is imported through the
XML data import like any other EDX file.

Funds are grouped by the rule set they are described in. The directory name is the
rule-set code - the value of `<s rule="...">` in the files it holds - so the rule set
(and the package that provides it) must be installed before the import.

| Directory | Rule set | Packages needed |
|-----------|----------|-----------------|
| `ZP2015/` | ZP2015 (Czech rules for archival description) | `CZ_BASE`, `ZP2015` |

## ZP2015

`ZP2015/mnv-lhota.xml` - *Místní národní výbor Lhota*, a fictitious fund of a local
national committee (1945-1980) described as an inventory: series, files, books, a map
of five sheets, photographs, storage units and the entities they refer to (the
originator, persons, places).

- The fund belongs to institution `215000010` from the CZ_BASE institution list
  (`package-cz-base/src/all-institutions-import.xml`); import that list first.
- The data does not contradict the rules, but the description is not complete: reference
  codes and serial numbers are generated by the ZP2015 bulk actions after the import,
  and most books and files have no storage unit yet.
- `Zp2015DemoDataImportTest` (elza-core) imports the file with the current rules and
  fails when it no longer imports or starts to violate them - keep it passing when the
  format or ZP2015 changes.
